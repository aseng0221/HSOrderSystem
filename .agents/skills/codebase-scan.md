# Skill: Deep Context Analysis

- **Command:** Use `grep_search` or `list_files` before any code generation.
- **Goal:** Identify existing patterns for:
  - File naming (kebab-case vs PascalCase)
  - Style management (NativeWind classes or Stylesheet)
  - Navigation patterns (React Navigation or Expo Router)
- **Constraint:** Do not create a new component if a similar one already exists in `src/components`.
