# Task Request
The user requested to switch authentication to a passwordless magic link flow. Furthermore, they need configuration instructions/implementations for Deep Linking on both Android and iOS so the authentication links redirect back to the app smoothly.

# Plan
1. Provide instructions and implementations for setting up Android App Links in `AndroidManifest.xml` and Universal Links in `ios/HSOrderSystem/HSOrderSystem.entitlements` utilizing placeholder authentication domains.
2. Update `LoginScreen.tsx` to handle passwordless sign-ins using `sendSignInLinkToEmail`.
3. Add utility functions in `src/utils/storage.ts` to save the email state prior to leaving the app.
4. Set up an app-wide listener in `AppNavigator.tsx` utilizing React Native's `Linking` library to parse magic links, authorize via Firebase, and push new users to the `ProfileSetup` process.

# Actions Taken
* `android/app/src/main/AndroidManifest.xml`: Placed an intent-filter to route incoming deep links towards the app.
* `ios/HSOrderSystem/HSOrderSystem.entitlements`: Placed the `com.apple.developer.associated-domains` required for routing incoming Universal Links.
* `src/utils/storage.ts`: Built `saveEmail` and `getSavedEmail` local storage hooks.
* `src/screens/LoginScreen.tsx`: Updated the flow to use `auth().sendSignInLinkToEmail(email, actionCodeSettings)`. Removed standard password fields to respect the passwordless request.
* `src/navigation/AppNavigator.tsx`: Constructed an `useEffect` that catches `Linking` events globally, executes `auth().signInWithEmailLink`, routes new users to `ProfileSetupScreen`, and fully authenticates the session automatically.
* Addressed code review feedback to strip out leftover password UI references.
* Verified TypeScript type safety using `npx typescript@latest/tsc --noEmit`.
