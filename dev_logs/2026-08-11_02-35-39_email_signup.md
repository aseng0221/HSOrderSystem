# Task Request
The user requested to switch authentication from Phone/SMS to Email signup/login to save verification costs. Additionally, the flow needs to force users to verify their email and then collect their Name and Contact Number in a profile setup step before allowing them to access the main application.

# Plan
1. Create `ProfileSetupScreen` to collect name and phone number and write to the Firestore user profile.
2. Update App Navigation to include the `ProfileSetupScreen` and restore `OTPScreen` in the stack for future use.
3. Overhaul `LoginScreen` to use `auth().createUserWithEmailAndPassword()` and `auth().signInWithEmailAndPassword()`. Add checks for email verification and immediate signouts for unverified users to prevent bypassing the auth wall. Add a Forgot Password reset flow.
4. Update `useAuthViewModel.ts` to hook `isAuthenticated` global state to both `user.emailVerified` and `profileCompleted` (checked via `displayName` and `phoneNumber` existence in the synced Firestore profile document).
5. Pre-commit tests and documentation.
