# Task Request
The user requested to switch authentication to a passwordless magic link flow. Furthermore, they need configuration instructions/implementations for Deep Linking on both Android and iOS so the authentication links redirect back to the app smoothly. Additionally, they needed to resolve the "Site Not Found" error that appears when the link is opened in a desktop environment.

# Plan
1. Configure Android App Links in `AndroidManifest.xml` and Universal Links in `ios/HSOrderSystem/HSOrderSystem.entitlements` utilizing the Firebase Auth domain (`hsordersystem.firebaseapp.com`).
2. Update `LoginScreen.tsx` to handle passwordless sign-ins using `sendSignInLinkToEmail`.
3. Add utility functions in `src/utils/storage.ts` to save the email state prior to leaving the app.
4. Set up an app-wide listener in `AppNavigator.tsx` utilizing React Native's `Linking` library to parse magic links, authorize via Firebase, and push new users to the `ProfileSetup` process.
5. Setup `public/index.html` and `firebase.json` for Firebase Hosting fallback page.

# Actions Taken
* `android/app/src/main/AndroidManifest.xml`: Placed an intent-filter pointing to `hsordersystem.firebaseapp.com` to route incoming deep links towards the app.
* `ios/HSOrderSystem/HSOrderSystem.entitlements`: Placed the `com.apple.developer.associated-domains` configured to `hsordersystem.firebaseapp.com` for routing incoming Universal Links.
* `src/utils/storage.ts`: Built `saveEmail` and `getSavedEmail` local storage hooks.
* `src/screens/LoginScreen.tsx`: Updated the flow to use `auth().sendSignInLinkToEmail(email, actionCodeSettings)`. Removed standard password fields to respect the passwordless request. Configured a fallback to allow entering an email manually via `route.params` if the email is lost during the magic link click process.
* `src/navigation/AppNavigator.tsx`: Constructed an `useEffect` that catches `Linking` events globally, executes `auth().signInWithEmailLink`, and routes new users to `ProfileSetupScreen`.
* `firebase.json` and `public/index.html`: Created a user-friendly webpage and wired Firebase Hosting directives to fix the "Site Not Found" desktop issue.
* Addressed code review feedback fixing placeholder domains and removing a dangerous automatic stack navigation to `MainTabs`.
* Verified TypeScript type safety using `npx typescript@latest/tsc --noEmit`.
