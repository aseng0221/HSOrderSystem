# Task: Edit Profile implementation with birthdate

## Request
I want user to edit their profile. in the edit profile screen, user can edit their name and contact number, but not email address. User can select their birthdate here, if the birthdate is null. If it is existing, the birthdate will not be editable.

## Plan
1. Update `UserProfile` type in `src/types/user.ts` to include `birthdate` (optional string or Date/timestamp format, string 'YYYY-MM-DD' is fine).
2. Create an `EditProfileScreen.tsx` in `src/screens`.
   - It should allow editing `displayName` and `phoneNumber`.
   - `email` should be displayed but read-only.
   - Show `birthdate` field. If `birthdate` exists on the user's profile, it is read-only. If it is null/undefined, it is editable using `@react-native-community/datetimepicker`.
3. Read the newly created `src/screens/EditProfileScreen.tsx` file using `read_file` to verify the creation and content.
4. Add `EditProfileScreen` to `AppNavigator.tsx` stack group.
5. Update `AccountScreen.tsx` to navigate to `EditProfileScreen` when the "Edit Profile" menu item is pressed.
6. Verify the changes using tests (`npm test`, `npm run lint`, `npx typescript@latest/tsc --noEmit`).
7. Complete pre commit steps to ensure proper testing, verification, review, and reflection are done.
8. Submit the change.

## Actions taken
- Added `birthdate` property to `UserProfile` interface.
- Created `EditProfileScreen` with `displayName`, `phoneNumber`, `email` and `birthdate` functionality.
- Installed `@react-native-community/datetimepicker`.
- Updated `AccountScreen` to navigate to `EditProfileScreen`.
- Registered `EditProfileScreen` in `AppNavigator`.
- Ran linter, typescript compiler, and tests.
- Reviewed code and fixed a bug where `refreshProfile` was called but not defined in `useAuthViewModel`.
