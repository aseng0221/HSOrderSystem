# Task Log: Hide URL in iOS Simulator

## Task Request
User asked: "is it possible not to show the url link at the top?"
(This referred to a screenshot from an iOS Simulator showing a Safari View Controller with a URL `https://www.oneusefulthing.org/...` being loaded during the Firebase Auth flow).

## Plan
1. Investigate the codebase to identify the source of the WebView or Safari View Controller.
2. Determine if the URL can be hidden.
3. Provide an explanation and potential workarounds.

## Actions & Updates
- Investigated `src/screens/LoginScreen.tsx` and found it uses `@react-native-firebase/auth` for phone authentication (`signInWithPhoneNumber`).
- The screenshot showed an `SFSafariViewController` popping up. This happens in Firebase Phone Auth on iOS when silent APNs (Apple Push Notification service) verification fails or is not configured. Since it's running on an iOS Simulator, APNs verification is not supported, forcing Firebase to fall back to a web-based reCAPTCHA verification.
- **Why it cannot be hidden:** Apple strictly enforces that `SFSafariViewController` and native browser modals display the domain/URL of the loaded page for security and anti-phishing reasons. Therefore, it is **impossible** to hide the URL link at the top of this view via code.

## Proposed Workarounds
Since the URL cannot be hidden in the fallback view, the solution is to prevent the fallback view from appearing entirely:
1. **Test on a Physical Device:** If APNs is properly configured in the Apple Developer console and Firebase, running the app on a physical device will allow the background APNs check to succeed, bypassing the reCAPTCHA browser completely.
2. **Use Firebase Test Phone Numbers:** You can configure a test phone number and a fixed OTP in the Firebase Console (Authentication > Sign-in method > Phone > Phone numbers for testing). Using this test number in the simulator bypasses the reCAPTCHA and SMS sending entirely, allowing seamless testing without the browser popup.
3. **Configure Firebase App Check:** In some configurations, App Check can act as the primary attestation provider, further reducing reCAPTCHA requirements.
